You are running the Claude Code MD System — ENV EXPORT process.
This exports your full global Claude Code environment, not just one project.

---

## Step 1 — Locate Global Claude Directory

Determine `~/.claude/` path:
- macOS/Linux: `~/.claude/`
- Windows: `C:\Users\[username]\.claude\`

---

## Step 2 — Collect All Components

Read each of the following if it exists. Note which are missing.

1. `~/.claude/CLAUDE.md` — global rules and behaviour
2. `~/.claude/settings.json` — global permissions and hooks
3. `~/.claude/projects.md` — project registry
4. All files in `~/.claude/commands/` — list names + read content
5. All `.js` files in `~/.claude/hooks/` — list names + read content
6. MCP servers — extract from `settings.json` `mcpServers` key if present

---

## Import Instructions

1. Copy this file to any folder on the new machine
2. Open Claude Code in that folder
3. Run: `/cc-env-import`
4. Choose Merge or Replace for each component
5. Re-enter any API keys for MCP servers
6. Update project paths in the registry if they differ on this machine
7. Run: `/cc-audit` in each project to verify setup
